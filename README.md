# Tugas ArrayList

Program simulasi rekening bank sederhana. Class Bank_2 menyimpan
saldo dan menggunakan ArrayList untuk mencatat riwayat transaksi
(deposit dan withdraw).

## Cara menjalankan

```
javac *.java
java DemoBank
```

## Library tambahan

Tidak ada, hanya java.util.ArrayList.
